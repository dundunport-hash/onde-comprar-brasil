# UI de eletrônicos

Meta: aparência moderna, comercial, responsiva e mais visual que a versão de farmácia.

Prioridades:

- hero promocional enxuto;
- busca visível;
- categorias por imagem/ícone;
- cards com imagem dominante, marca, título curto, preço, desconto/parcelamento, avaliação/estoque quando houver e CTA claro;
- descrição longa apenas na página de produto;
- filtros úteis: categoria, marca, preço, avaliação e disponibilidade quando os dados permitirem;
- página de produto com galeria + preço/CTA + especificações + garantia/entrega;
- hierarquia visual consistente e mobile-first.

Não copiar visual/asset de terceiros literalmente. Use referências apenas para composição, densidade, hierarquia e UX.
